# DjVu Reader

เว็บแอปสำหรับอ่านไฟล์ `.djvu` ในเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมใดๆ และไฟล์จะถูกอ่านในเครื่องของคุณเท่านั้น โดยไม่มีการอัปโหลดไปที่ใด

**ใช้งานออนไลน์:** https://ardsaleep-arch.github.io/djvu-reader/

## ฟีเจอร์
- เปิดไฟล์ได้ทั้งจากปุ่ม “เปิดไฟล์” และการลากไฟล์มาวาง
- เลื่อนอ่านต่อเนื่องได้ทุกหน้า โดยจะแสดงผลเฉพาะหน้าที่กำลังดูอยู่ จึงเปิดไฟล์ใหญ่ได้
- ซูมได้หลายแบบ: พอดีความกว้าง / พอดีหน้า / 50–300% / Ctrl หรือ ⌘ + ล้อเมาส์ (รวมถึง pinch บน trackpad)
- มีแถบข้างแสดง **รูปย่อ** และ **สารบัญ** (ถ้าไฟล์มี) ซึ่งคลิกเพื่อไปยังหน้านั้นได้
- **ค้นหาข้อความ** พร้อมไฮไลต์ตำแหน่งที่พบบนหน้า และเลือกข้อความเพื่อคัดลอกได้ (ใช้ได้เฉพาะไฟล์ที่มีชั้นข้อความ/OCR)
- **จำหน้าที่อ่านล่าสุด** ไว้ เมื่อเปิดไฟล์เดิมอีกครั้งจะกลับไปยังหน้าเดิมให้อัตโนมัติ
- รองรับธีมมืดตามการตั้งค่าของระบบ และมีโหมดเต็มจอ

## ปุ่มลัด
| ปุ่ม | การทำงาน |
|---|---|
| ← / → | หน้าก่อน / หน้าถัดไป |
| Home / End | หน้าแรก / หน้าสุดท้าย |
| Ctrl/⌘ + / − | ซูมเข้า / ออก |
| Ctrl/⌘ 0 | พอดีความกว้าง |
| Ctrl/⌘ F | ค้นหา |

## รันในเครื่อง
ต้องเปิดผ่าน local server (เปิดไฟล์ `index.html` โดยตรงแบบ `file://` จะใช้งานไม่ได้):
```sh
python3 -m http.server 8000
```
จากนั้นเปิด http://localhost:8000
